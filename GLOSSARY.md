# WzComparerR2-Rust

Rust toolkit for reading, comparing, and rendering MapleStory WZ archives.
This context owns the WZ format model, the string tables, avatar/map data, and the
oracle-based parity contract.

## Language

### Archive format

**WZ archive**:
A game data container (`.wz`) made of a directory tree and separately encrypted image payloads.
_Avoid_: WZ file, package, container

**WZ image**:
An `.img` entry inside a WZ archive: a property tree whose leaves are scalars, UOLs, or canvases.
_Avoid_: image file, sprite sheet

**Property node**:
A named node in a WZ image tree. It holds a scalar, a UOL, or children.
_Avoid_: entry, item, field

**Canvas**:
A WZ image leaf holding compressed pixels plus placement metadata (`origin`, `map`, `z`, `group`, `_outlink`).
_Avoid_: sprite, bitmap, texture

**UOL**:
A node whose value is a path to another node. Resolution starts at the link's parent and may cross image boundaries.
_Avoid_: reference, pointer, alias

**Directory tree**:
The archive-level index mapping image paths to offsets. It is separate from the image contents.
_Avoid_: file table, TOC

**Format profile**:
The encryption and layout generation detected from an archive header (PKG1, PKG2, MS, hash version, …).
_Avoid_: version, format version

**Game data root**:
The user's local `Data` directory containing the WZ archives.
_Avoid_: data folder, game folder

### String data

**String table**:
`String.wz`'s per-domain index from numeric ID to name/description.
_Avoid_: localization table, text database

**String root**:
One of the five WZ roots the C# `StringLinker` reads: String, Item, Etc, Quest, Reactor.
_Avoid_: string file

**StringLinker**:
The module that loads string roots into per-domain ID maps.
_Avoid_: text loader, name resolver

**StringResult**:
The resolved name, description, and metadata for one ID.
_Avoid_: string entry, record

**StringRoots**:
The five-root input to `StringLinker::load_roots`; only the String root is required.
_Avoid_: string set, sources

### Avatar

**ZMap**:
The canonical z-order list that decides which avatar layer draws in front.
_Avoid_: draw order, layer order

**Bone**:
A node in the avatar skeleton; it carries skin layers and child bones.
_Avoid_: joint, pivot

**Skin layer**:
A drawable canvas attached to a bone with a `z` tag.
_Avoid_: sprite, part

**Avatar scene**:
The assembled bone/skin/zmap structure ready for rendering.
_Avoid_: avatar model, character

**Prism**:
An HSV color transform applied to avatar canvas layers.
_Avoid_: tint, color filter

### Map

**Map data**:
Parsed map metadata: `info`, backgrounds, objects/tiles, footholds, portals, and life.
_Avoid_: map file, level

**Foothold**:
A walkable line segment on a map.
_Avoid_: platform, floor

**Life**:
An NPC or monster placement on a map.
_Avoid_: entity, spawn

### Verification

**Oracle**:
The external C# `WzComparerR2.Oracle` harness used as the behavioural reference.
_Avoid_: reference implementation, baseline

**Gate op**:
An oracle operation whose output must match the C# oracle after normalization.
_Avoid_: test, check

**Advisory op**:
An oracle operation whose output difference is reported but does not fail the gate.
_Avoid_: warning, soft check

**Uncomparable op**:
An oracle operation the C# harness cannot run (stub or missing project).
_Avoid_: skipped, unsupported

**Synthetic corpus**:
Deterministic WZ fixtures generated by `tools/corpus-builder` for CI and tests.
_Avoid_: mock data, test data

**Replay**:
A saved artifact directory (`rust.json`, `csharp.json`, exit codes) re-judged without running either side.
_Avoid_: fixture, snapshot

**Pinned commit**:
The exact C# commit the oracle is compared against.
_Avoid_: version, ref
